# Stage 8.2 — Cable Loss source and method

The supplied manual covers cable-length resonance measurements with an open/short end, but does not prescribe Cable Loss math or calibration. External VB6 artifacts contain `fraCableLoss`, the `CABLE LOSS dB` label, and the selected-mode string handled by `VB6_00425e1d`; recovered code switches mode-specific controls but does not establish a loss formula or calibration reference.

Decision: retain `−ReturnLossDb / 2` as a separately documented VNA Studio one-port estimate, not a legacy port. The EN/PL docs now state the provenance and the physical comparison still pending. Independent review found no blockers. No hardware was accessed.
