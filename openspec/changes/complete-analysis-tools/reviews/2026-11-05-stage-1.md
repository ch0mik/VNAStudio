# Etap 1 — inwentaryzacja trybów

| Tryb | Bieżąca logika | Dowód i ograniczenie |
| --- | --- | --- |
| Cable Loss | Tryb jest wybieralny, ale ekran pokazuje niedostępność. | VB6 zawiera nazwę trybu, lecz dostępny handler dowodzi tylko przełączania kontrolek. Instrukcja nie określa metody Cable Loss. |
| Cable Length | Długość z M1/M2 i VF: `VF × c / (2 × Δf)`. | Instrukcja wymaga kabla open/short i sąsiednich szczytów albo sąsiednich dołków. UI obecnie nie weryfikuje sąsiedztwa/rodzaju. |
| Xtal | Ręczne `Q = Fres / (Fh − Fl)`. | Instrukcja mówi, że automat XTAL oryginału nie był zaprogramowany; ręczne odczyty fazy są dodatkiem VNA Studio. |
| Filter | Tryb jest wybieralny, ale ekran pokazuje niedostępność. | Instrukcja opisuje pasmo transformatora/filtra między portami, a INI ma `RL_OFFSET_filter=15.5` dla punktu zerowego OUT–IN. Brak dowodu zespolonego S21. |
| Generator | Dziesięć pamięci z INI, edycja częstotliwości, walidacja zakresu; wyjście wyłączone. | W INI są wyłącznie częstotliwości pamięci. Nie odzyskano komendy sterującej generatorem. |

Granica: nie wolno traktować podpisanego S11 jako odpowiedzi S21. Cable Loss i FILTER nie zostaną uzupełnione przez zgadywanie algorytmu. Komendy nadajnika nie będą wysłane bez testowalnego kontraktu.

## Review

Niezależny subagent porównał inwentaryzację z INI, instrukcją, odzyskanym handlerem VB6 i bieżącym kodem. Nie znalazł błędów faktograficznych ani blockerów. Potwierdził, że weryfikacja sąsiedztwa rezonansów jest luką Cable Length, a Filter nie może deklarować S21 na podstawie samego istniejącego S11.
