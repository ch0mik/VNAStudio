# Stage 6 — Generator review

The supplied manual documents ten editable frequency memories and says the OFF-labeled control toggles generator output. VB6 recovery shows the state-toggle branch and a literal `&OFF`, but does not recover a full verified sequence for enabling/disabling output and setting frequency. The implementation therefore retains memory editing/range validation while leaving hardware output disabled. UI copy states that VNA Studio sends no command and that the physical output state is unknown.

Independent review found no blockers. Tests cover memory preset selection, out-of-profile frequency rejection, and disabled output. No COM access was made.
