# Etap 3 — Xtal

Instrukcja dostarczonego programu potwierdza, że automatyczna zakładka XTAL nie była zaprogramowana. Zachowano ręczny kalkulator Q jako jawnie opisaną funkcję pomocniczą, bez automatycznej detekcji punktów fazy czy obwodu zastępczego kryształu.

Regresja odtwarza przykład 14,400 / 14,312 / 14,4816 MHz (Q≈84,9), sprawdza profil od 1 do 65 MHz i odrzuca odwrócone krawędzie. Zasoby PL/EN i instrukcja opisują ręczną metodę.

Testy zakresu: 5 zaliczonych, 0 błędów. Niezależny subagent nie znalazł blockerów.
