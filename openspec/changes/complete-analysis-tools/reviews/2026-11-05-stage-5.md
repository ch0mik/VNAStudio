# Stage 5 — Filter review

Review initially found a blocker: mode `1` was inferred from a related MAX4 device and the serial driver would have sent it to the user's VNA 1–65 MHz without confirmation. The implementation was changed so `MiniVnaSerialDevice` rejects scalar-transmission sweeps before any COM write/read and provides a localized error. Filter remains available for demo data and playback sessions, with transmission samples separate from reflection/SWR/impedance.

The EN/PL communication guides and Filter documentation were updated to state the variant limitation. The Filter panel also states that hardware scans are disabled pending device-specific command verification. Review confirmed the blocker and UI suggestion are resolved; no further findings. No COM access was performed.

Targeted verification: 60 tests passed for protocol rejection, scalar conversion, playback, session migration, and Cable Loss; UI build passed. The physical Filter fixture/command test remains pending because the current setup is a 50 Ω load on ANT with WOB disconnected.
