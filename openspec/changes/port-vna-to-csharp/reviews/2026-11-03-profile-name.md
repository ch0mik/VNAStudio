# Nazwa profilu urządzenia — 2026-11-03

Na prośbę użytkownika nazwa widoczna w panelu ustawień to `AD9851 · 65 MHz · analyz.ini`. Zmieniono nazwę w bundlowanym INI, domyślnych typed options i statycznym profilu, aby te źródła nie podawały różnych etykiet. Podglądy README wygenerowano ponownie.

Identyfikator `iw3hev-65mhz` pozostał taki sam: istniejące sesje są dopasowywane według identyfikatora, a zapisany historyczny snapshot może zachować swoją pierwotną nazwę. Komentarze dostarczonego INI wymieniają AD9851 jako przykład dla zegara około 192 MHz; nie stanowi to odczytu sprzętu ani potwierdzenia układu w danym egzemplarzu.

Weryfikacja: przegląd spójności trzech źródeł nazwy i dopasowania sesji, wizualny przegląd podglądu oraz kompilacja Release i 59/59 testów.
