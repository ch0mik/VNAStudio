# Plot zoom in/out

Added visible +/− buttons and focused-plot keyboard handling (Add/OemPlus/Subtract/OemMinus). Tooltips are localized in EN/PL. The commands halve/double the current horizontal frequency span around its center, shift the window inside profile bounds when needed and stop at a minimum width of 1 Hz or the complete profile width. They do not modify scan inputs, samples, calibration or marker frequencies.

All changes use the existing view-history stack, so Previous range restores the exact previous view, including the automatic full-data sentinel. Full range continues to reset to the captured data extent. Zoom out can expand beyond captured data to the profile limits, like the existing Profile range action. Enabled states update after data/view changes. Marker keyboard arrows retain their existing behavior.

A completed scan with the same SweepSettings preserves the current view and history, making zoom usable during continuous refresh. A changed frequency range or sample count resets the view. No device commands were added and no COM connection is needed to zoom.

Tests verify unchanged data/marker/scan settings, undo history, repeated zoom to 1 Hz and profile bounds, actual pointer clicks and key events in a 1024x768 window, and preserving/resetting zoom on same/changed sweep settings. Targeted zoom/localization tests passed 18/18 before the full regression suite.

Final validation: 140/140 Debug tests passed, strict OpenSpec validation passed, and all seven published previews were refreshed. The minimum-size preview was visually inspected. An independent subagent reviewed range bounds/overflow, command availability, keyboard routing, shared history and same/changed scan behavior; no blocking issue was found. No hardware scan was performed for this display-only change.
