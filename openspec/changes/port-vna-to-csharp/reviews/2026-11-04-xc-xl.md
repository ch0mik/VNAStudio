# Review U10 — marker Xc/Xl display

Date: 2026-11-04.

- Added a persisted Display checkbox and optional marker-table column.
- For a valid sample, negative signed reactance is shown as capacitance `C = 1/(2πf|X|)` in pF; positive reactance is shown as inductance `L = X/(2πf)` in µH. Zero, missing/invalid X and nonpositive frequency show an em dash.
- The original EXE contains `chkXJ`, `txtMkr1XJ`, `txtMkr2XJ`, and conversion captions `Xc to pf`/`Xl to uH`; these support interpreting it as marker readout conversion. No hardware calibration or sign convention was copied from names alone.
- Verification: full Release suite, 66 passed, 0 failed. Tests check capacitive and inductive examples at 1 MHz/2 MHz. Strict OpenSpec validation passes.
- Limitation: hardware sign convention remains to be compared with an actual signed sample from the device.
