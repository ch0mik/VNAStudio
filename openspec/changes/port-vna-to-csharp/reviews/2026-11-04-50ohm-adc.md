# 50-ohm ADC conversion review

The user confirmed a 50-ohm termination on the physical VNA. Scanning COM9 exposed incorrect positive signed S11 and missing SWR in the previous universal ADC*resolution−20 conversion.

The recovered original RF path establishes affine magnitude correction before reference subtraction, VNA_type polarity/reference and RL offset subtraction after polarity. For the supplied type-1 profile with zero offsets, signedS11=20.16−magnitudeADC*Adc_magres. The serial driver now uses RfSampleCalculator.FromLegacyAdcReadings without applying affine corrections twice. The existing general FromScaledReadings API is retained for its existing signed-input contract.

Three real 649-point scans produced finite SWR for every sample. Median SWR was about 1.036; all three resistance ranges were near 50 ohm. Peak SWR varied up to 1.258. The complete table, captured conditions and limits are in `docs/measurements/2026-11-04-com9-50ohm.md`.

An independent subagent checked the assembly constants/control flow, conversion code and regression expectations, and recalculated all 649 corrected samples using the original inverse-reflection algebra. No blocking issue was found. Mathematical agreement does not establish instrument accuracy, load tolerance or connector quality.

Remaining limits: original CSV/RF paths differ for nonzero RL offsets; the implementation follows RF magnitude processing. PH_b currently follows the CSV degree convention, with equivalence to RF confirmed for the supplied PH_b=0 only. The original takes ABS(X), so the physical reactance sign is not established. Open/short and direct original-program measurement comparisons remain outstanding.

Validation: full Release suite passed 133/133 tests, including a captured 50-ohm ADC pair and both VNA_type affine/polarity/offset cases.
