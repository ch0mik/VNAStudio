# RL×2 display range

## Evidence

The Analyser 306b screenshot labels a checkbox `RL x2`. Recovered handler `VB6_0043094f` selects RL tick-label branches `0, 10, 20, 30` and `0, 20, 40, 60`, and assigns separate graph limits. The exact VB control-to-branch mapping is not symbolized, so the implementation follows the screenshot label and the matching range values.

## Implementation

Added a localized, persisted `RL ×2` checkbox. It selects a 0–60 dB return-loss axis and matching curve transform; the default remains 0–30 dB. It does not modify point values, calibration, or session data.

## Verification

- Axis tick and coordinate tests cover the 0–60 dB scale.
- Avalonia tests cover binding, settings reload, and JSON persistence.
- Full Release test suite and strict OpenSpec validation were run after implementation.

## Limit

Pixel-for-pixel comparison with the original handler on identical measurement samples remains open.
