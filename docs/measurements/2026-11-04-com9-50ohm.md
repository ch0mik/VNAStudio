# 50-ohm termination check on COM9

Date: 2026-11-04, Europe/Warsaw. The user identified the connected load as a 50-ohm termination. Its tolerance, connector/adaptor characteristics and calibration certificate are unknown.

Three scans used the real application Start command, COM9 at 115200/8N1, the bundled VNA 1-65 MHz profile, 1–65 MHz, 649 points and SVNA=0. Each returned 2596 bytes and committed 649 samples. All samples had finite SWR after correcting the ADC conversion.

| Capture | Minimum SWR | Median SWR | Maximum SWR | Resistance range |
| --- | ---: | ---: | ---: | ---: |
| Corrected scan | 1.0302 | 1.0361 | 1.1534 | 50.38–52.72 ohm |
| Repeat 1 | 1.0304 | 1.0358 | 1.1235 | 50.42–51.96 ohm |
| Repeat 2 | 1.0304 | 1.0358 | 1.2580 | 50.32–51.75 ohm |

The corrected scan had signed S11 between −36.56 and −22.95 dB, corresponding to positive return loss 22.95–36.56 dB. At approximately 1, 14 and 64.9 MHz it gave:

| Frequency | SWR | Resistance | Magnitude of reactance |
| --- | ---: | ---: | ---: |
| 1.0000 MHz | 1.0363 | 50.76 ohm | 1.63 ohm |
| 14.0169 MHz | 1.0353 | 51.49 ohm | 0.95 ohm |
| 64.9014 MHz | 1.0796 | 50.62 ohm | 3.80 ohm |

An ideal 50+j0-ohm load on a 50-ohm reference has SWR 1. The observed data are broadly consistent with a near-50-ohm load. Peaks above SWR 1.1 occur at different frequencies between scans (46, 11 and 14 samples respectively), so repeatability and absolute accuracy should not be inferred from the median alone. These captures do not isolate errors of the analyser, termination or connections.

## Source comparison and fix

The previous conversion used ADC*Adc_magres−20 for both variants, producing positive signed S11 and no SWR for this load. The recovered original RF path uses an affine ADC correction before reference subtraction, VNA_type-dependent polarity/reference and then subtracts the RL offset. For the supplied VNA_type=1 profile with default affine coefficients and zero offsets:

```text
signedS11Db = 20.16 - magnitudeADC * 0.058651026
phaseDegrees = phaseADC * 0.175953079
```

An independent reviewer compared all 649 corrected samples to the original inverse-reflection algebra: RL/phase matched exactly; SWR differed by less than 2.3e−16, R and |Z| by less than 3.6e−14. This confirms the mathematical implementation for the default profile; it is not an independent calibration of the hardware. Nonzero PH_b and the physical sign of reactance remain unverified. Legacy CSV/RF formulas also differ for nonzero RL offsets; the implementation follows the RF magnitude path.

Regression tests cover a real captured ADC pair, both VNA_type polarities and affine/offset order. The full Release suite passed 133/133 tests.

Full raw captures and temporary hardware-probe projects are retained outside the GitHub source tree. This public report contains the summarized measurements; regression tests retain a small captured ADC vector. Original binaries and decompilation also remain outside VnaStudio.

## Repeat scan on COM9

Date: 2026-11-05, Europe/Warsaw. The user confirmed COM9 was connected with the same 50 Ω termination. A fresh 1–65 MHz, 649-point sweep through the production `MiniVnaSerialDevice` completed and returned 649 points. It reported SWR min/median/max of 1.0302 / 1.0356 / 1.1026, resistance 50.40 / 51.30 / 51.79 Ω, and median |X| of 1.26 Ω. The device samples remain `Ambiguous (LegacyVna65Mhz)` for phase sign.
